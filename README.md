# ai-dev-guide

AI駆動開発のためのルール集。VibeOps思想に基づいた開発ガイドライン。

## 概要

このリポジトリは、AIと協働して開発を進める際の共通ルールとテンプレートを提供します。

## ファイル構成

- `DEV-RULES.md` - AI開発ルール（VibeOps統合版）

## 使い方

1. `DEV-RULES.md` の「開発ルール（コピペ用）」セクションをコピー
2. 「Spec」セクションにプロジェクト固有の仕様を記入
3. AIに投げて開発開始

## 思想

> 「速く作る」ではなく「壊れずに回り続ける」

- 書くのはAI
- 決めるのは人
- 守るのはルール
